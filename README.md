# RunPath — от дивана до марафона

PWA на русском, которое ведёт новичка от первой прогулки до финиша марафона. Работает полностью офлайн, все данные — на устройстве.

```
npm install
npm run dev        # разработка
npm run check      # typecheck + lint + test + build
```

**Приложение работает:** https://pavel198788.github.io/runpath/

Открывается с телефона, ставится на домашний экран, работает без интернета. Аккаунт не нужен: все данные хранятся на устройстве.
