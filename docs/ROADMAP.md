## Что проверить руками после A0

1. `npm run dev`, открыть на телефоне в той же сети (`npm run dev -- --host`), убедиться, что нижняя навигация удобна большим пальцем.
2. Переключить тему в «Ещё» — должна меняться мгновенно и сохраняться после перезагрузки.
3. `npm run build && npm run preview`, открыть, затем выключить сеть — приложение должно открываться (плашка «Нет сети» сверху).
4. В Chrome: «Установить приложение» — иконка оранжевая с белой дорожкой.
