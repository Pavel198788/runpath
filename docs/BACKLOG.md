- ✅ Запись тренировки (после таймера и вручную), дневник, прогресс

### A2 Трекинг, импорт, адаптация ✅

### A3 Питание ✅

- ✅ Библиотека продуктов (274 позиции, КБЖУ, категории) и 34 рецепта в `content/`, zod-валидация тестом
- ✅ Расчёт BMR/TDEE (Mifflin-St Jeor), калорийность по дню плана (отдых / лёгкая / длительная / старт)
- ✅ Макросы по фазам (углеводы 4–10 г/кг, белок 1,4–1,8 г/кг, жиры ≥ 0,8 г/кг) с объяснением «почему»
- ✅ Цель по весу: мягкий дефицит ≤ 500 ккал и ≤ 15 %, запрет дефицита на пиковых неделях и тейпере, минимумы, предупреждение RED-S
- ✅ Питание вокруг тренировки: до / во время (30–60 г/ч при > 75–90 мин) / после; гидратация и электролиты, жара
- ✅ Углеводная загрузка (2–3 дня) и план питания на день старта по часам; «тренировка желудка» на длительных
- ✅ Экран «Питание»: цели дня, лёгкий дневник («поел нормально / мало / переел») и дневник по продуктам с поиском
- ✅ Рецепты с тегами (до бега / после / для длительной / вегетарианское); шаблоны рационов — через рецепты и кнопку «в дневник»
- ✅ Редактирование профиля (вес, рост, цель по весу) в «Ещё»

### A4 Травмы, обучение, мотивация, калькуляторы 🔨

- ⏳ Библиотека упражнений: разминка, заминка, растяжка, ОФП, мобильность (текст + простые SVG-схемы)
- ⏳ Симптом-чекер по болям (без диагнозов): типичные причины у новичков, что делать, когда к врачу
- ⏳ Самочувствие: сон, стресс, пульс покоя → индекс готовности; предложение заменить тренировку на лёгкую
- ⏳ Обувь: пары, пробег, напоминание о замене на 600–800 км
- ⏳ Мини-курс «Бег для новичков», уроки привязаны к неделям плана; глоссарий с подсказками из интерфейса
- ⏳ Калькуляторы: темп ↔ время, прогноз Ригеля, пульсовые зоны, целевой темп марафона
- ⏳ Геймификация: путь 0 → 42,2 км, «пробежал как от … до …», стрики с заморозкой, достижения, уровни, еженедельный отчёт
- ⏳ Виртуальные челленджи, карточка результата (Canvas → PNG)
- ⏳ Схема тела для отметки болей (вместо списка)

### A5 Бэкап, ИИ BYOK, полировка ⏳

- ⏳ Экспорт/импорт всех данных JSON, восстановление из файла
- ⏳ ИИ-тренер BYOK (Anthropic / OpenAI-совместимый): чат с контекстом, «почему сегодня такая тренировка», разбор недели; системный промт `src/ai/coachSystemPrompt.ts`; ИИ только предлагает, применяет движок правил
