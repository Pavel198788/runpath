## Этап B — сервер (только после приёмки A)

### B0 Каркас API

- ⏳ `server/CHECK.php`: версия PHP, расширения, cron, HTTPS, лимиты, .htaccess
- ⏳ Slim 4 (или чистый роутер — решить по CHECK), Phinx-миграции, `.env`, деплой по SFTP из GitHub Actions
- ⏳ Заголовки безопасности, CORS, логирование в файл, rate limiting в БД

### B1 Аккаунты и синхронизация

- ⏳ Регистрация e-mail + пароль (Argon2id), подтверждение, сброс; JWT access + refresh
- ⏳ Гостевой режим сохраняется; «поднять» локальные данные в аккаунт
- ⏳ Outbox в IndexedDB, протокол «изменения после версии N», LWW по `updatedAt`, треки отдельными блобами
- ⏳ Индикатор синхронизации, ручная кнопка, удаление аккаунта одной кнопкой

### B2 ИИ-прокси

- ⏳ `api/v1/ai/*` с ключом владельца, квоты на пользователя и бюджет сервиса, учёт токенов, SSE при поддержке хостинга; BYOK остаётся запасным

### B3 Push и интеграции

- ⏳ Web Push (VAPID, `minishlink/web-push`), рассылка из cron, отключаемые типы, подсказка про iOS 16.4+
- ⏳ Strava OAuth, опрос из cron / webhook, лимиты API; интерфейс провайдера Garmin (после одобрения заявки)

### B4 Админка и аналитика

- ⏳ Контент с версиями (уроки, рецепты, продукты, упражнения, шаблоны), клиент подтягивает при синхронизации
- ⏳ Пользователи, квоты, флаги фич; приватная аналитика (DAU/WAU, воронка 5/10/21/42, отток, ошибки клиента с согласия)
