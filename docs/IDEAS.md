# Идеи «не сейчас»

Из ТЗ:

- Режим «пара/друг» — совместный план для двоих
- Клубы и лидерборды среди друзей (после сервера)
- «Живой» тренер-человек с доступом к данным ученика
- E-mail-дайджест недели
- Беговая дорожка: ввод без GPS, каденс через акселерометр
- Метроном каденса
- Подбор беговых стартов из редактируемого локального списка
- Интеграция с музыкой (темп плейлиста)
- Режим «после травмы — возвращение»
- Голосовой ввод заметок
- Обёртка Capacitor для App Store / Google Play (нативный фоновый GPS, HealthKit / Health Connect)
- Локальные ИИ-модели в браузере (WebLLM)
- Платная подписка (ЮKassa / CloudPayments) на расширенную ИИ-квоту
