# ADR-0002. Стратегия офлайна PWA

Дата: 2026-09-10 · Статус: принято

## Решение

- `vite-plugin-pwa` в режиме `generateSW`: вся статика в precache, навигация — на `index.html` (SPA).
- `registerType: 'prompt'`: новая версия не подменяется молча — пользователь видит «Доступна новая версия» и решает, когда обновиться (нельзя перезагружать страницу посреди тренировки).
- OSM-тайлы кэшируются `CacheFirst` (до 2000 тайлов, 90 дней), чтобы маршрут показывался офлайн для мест, где пользователь уже бегал.
- Ограничения, которые честно не решаются в PWA: фоновый GPS при заблокированном экране на iOS, push без сервера. Обходные пути описываются в фичах на A2/A5.
