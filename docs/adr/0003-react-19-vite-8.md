# ADR-0003. React 19 и Vite 8 вместо React 18

Дата: 2026-09-10 · Статус: принято

## Контекст

ТЗ называет React 18. На момент старта актуальны Vite 8 и `@vitejs/plugin-react` 6, у которого peer-зависимость `vite ^8`; React 19 — текущая стабильная ветка, React 18 более не получает фичи.

## Решение

Использовать React 19.3 + Vite 8. Все выбранные библиотеки (react-router 7, zustand 5, dexie-react-hooks 4, react-i18next 17, Testing Library 16) поддерживают React 19. Код не использует ничего, что отличалось бы от React 18 для нашей задачи.

## Последствия

Если понадобится вернуться на 18 — потребуется даунгрейд Vite до 7 и plugin-react до 5; исходники менять не придётся.
