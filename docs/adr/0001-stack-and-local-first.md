# ADR-0001. Стек и local-first архитектура

Дата: 2026-09-10 · Статус: принято

## Контекст

Нужно публичное PWA на русском, которое полностью работает офлайн, а сервер добавляется позже как необязательный плагин на shared-хостинге.

## Решение

- Vite + React + TypeScript strict; Tailwind v4 с токенами; собственные лёгкие компоненты вместо UI-фреймворка.
- Все пользовательские данные — в IndexedDB (Dexie) с версионированной схемой. Zustand — только для эфемерного UI-состояния (тема).
- Каждая сущность имеет `id` (UUID v4), `createdAt`, `updatedAt`, `deletedAt` (мягкое удаление), `syncVersion`. Это цена в несколько полей сейчас, но она позволяет добавить синхронизацию на этапе B без миграции данных пользователей.
- Серверные точки расширения — интерфейсы: `SyncAdapter`, `AiProvider`, `IntegrationProvider`. На этапе A их реализации — заглушки; `features.server = false`.
- Доменная логика в `src/domain/` не импортирует React и БД (проверяется ESLint) — это делает генератор плана и питание тестируемыми чистыми функциями.

## Последствия

- Любой экран можно проверить в авиарежиме без моков сервера.
- Синхронизация будет last-write-wins по `updatedAt`, журнал тренировок — append-only; конфликтов при одном пользователе на нескольких устройствах практически нет.
