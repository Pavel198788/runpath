# RunPath API — установка на обычный хостинг

Коротко: залить папку, создать базу, заполнить `.env`, применить миграции, добавить одно задание cron.

## 1. Что нужно от хостинга

PHP 8.2 или новее, база MySQL, планировщик задач (cron), HTTPS. Проверить всё сразу можно скриптом:
откройте в браузере `https://ваш-домен/api/CHECK.php`. Он покажет строчками, что есть, а чего не хватает.
После проверки файл лучше удалить.

## 2. Куда положить файлы

```
/домашняя-папка/
  .env                  ← секреты, ВЫШЕ веб-корня, наружу не доступен
  api/                  ← сюда содержимое папки server
    public/index.php    ← точка входа
    vendor/
    ...
/public_html/           ← сюда собранное приложение (папка dist)
```

Если хостинг не даёт положить `.env` выше корня, оставьте его рядом с `api/` — приложение найдёт оба варианта,
но тогда обязательно закройте его правилом в `.htaccess`.

Адрес API получится `https://ваш-домен/api/public/`. Чтобы было короче, направьте поддомен `api.ваш-домен`
на папку `api/public` или добавьте правило переадресации.

## 3. База и настройки

1. Создайте базу и пользователя в панели хостинга.
2. Скопируйте `.env.example` в `.env` и заполните: доступы к базе, `APP_URL`, `CLIENT_ORIGINS` (адрес приложения),
   `APP_KEY` (любая случайная строка от 64 символов — она подписывает токены и шифрует ключи интеграций).
3. Примените миграции: `php vendor/bin/phinx migrate -e production`.
4. Сделайте себя администратором: в базе у своей строки в таблице `users` поставьте `role = 'admin'`.

## 4. Cron

Добавьте задание раз в 5 минут:

```
php /домашняя-папка/api/cron/run.php
```

Если консольного cron нет, можно дергать по адресу `https://ваш-домен/api/cron/run.php?token=ЗНАЧЕНИЕ_CRON_TOKEN`.

Cron делает всю фоновую работу: отправляет push по расписанию, забирает тренировки из Strava, чистит старое.

## 5. Что включить по желанию

- **ИИ-тренер**: впишите `ANTHROPIC_API_KEY`. Лимиты (сколько сообщений в день на человека и месячный бюджет)
  настраиваются в админке, дефолты — в `.env`.
- **Push-уведомления**: сгенерируйте ключи `php cron/vapid.php` и впишите обе строки в `.env`.
- **Strava**: создайте приложение на strava.com/settings/api, впишите `STRAVA_CLIENT_ID` и `STRAVA_CLIENT_SECRET`,
  в настройках Strava укажите домен обратного вызова — ваш домен.

## 6. Приложение

Соберите клиент с адресом API:

```
VITE_API_URL=https://ваш-домен/api/public VITE_FEATURE_SERVER=true npm run build
```

и залейте папку `dist` в веб-корень. Без этих переменных приложение собирается полностью автономным:
никаких аккаунтов, всё на устройстве.

## Чего сервер намеренно не делает

- Не хранит логику плана и питания: она работает на устройстве и обязана работать без сети.
- Не держит постоянных соединений (WebSocket) — на обычном хостинге их нет. Приложение синхронизируется
  при открытии, по кнопке и раз в пять минут.
- Стриминг ответов ИИ работает, только если хостинг не буферизует вывод. Если буферизует, ответ придёт
  целиком — приложение это умеет и покажет его как обычно.
