# content/

Обучающие материалы, рецепты, продукты, упражнения — в JSON/Markdown. Каждый тип валидируется zod-схемой при сборке (появится на A3/A4). Правятся без правки кода.

## Откуда цифры

`nutrition/foods.json` — 230 продуктов и ингредиентов: средние значения КБЖУ на 100 г (напитки — на 100 мл)
по общедоступным таблицам пищевой ценности, плюс привычная мера (`portion`: «1 средний» — 120 г и т. п.).
Готовых блюд здесь нет намеренно: суп, плов и паста — это рецепты, они в `nutrition/recipes.json`.
Значения справочные и у конкретного производителя отличаются — в приложении об этом написано.
